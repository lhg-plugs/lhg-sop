# /lhg-sop:checklist —— 执行检查清单提取

用户输入在 `$ARGUMENTS` 中：`<SOP文档路径>`。

## 流程（加载 sop-checklist 全程指导）

### 1. 提取
从 SOP 文档的步骤中提取关键检查点，输出 `sops/checklist-<主题>.md`：
- 只保留"做错会出事"的检查点（不是把每个步骤都抄一遍）
- 每个检查项必须**可验证**：有明确的通过标准（数字/状态/有无），不许出现"仔细检查""及时处理"这类模糊词
- 每个检查项标注检查人（谁检查）和检查时机（什么时候检查）

### 2. 格式
```markdown
# 《XX流程》执行检查清单 v1.0（对应 SOP-XXX v1.2）
- [ ] 步骤3：工单状态已更新为"已派单"（检查人：调度员，时机：派单后即时）
- [ ] 步骤5：客户已收到短信通知（检查人：客服，时机：每日17:00批量核对）
```

### 3. 校验
跑一遍审计脚本的检查清单规则（SOP-CHK-001/002），模糊词和无检查人的项必须改掉。

## 硬规则
- 检查项不可验证（含模糊词）→ 不许。
- 检查项无检查人 → 不许。
- 检查清单与 SOP 版本脱钩（SOP 升级了清单没同步）→ 不许（清单头必须标注对应 SOP 版本）。
